Each level has:
• Own markdown file
• Own stage (seed→harvesting)
• Own priority score
• Own co-venturers / team
• Own deadlines
✓ Each level is independently queryable
✓ Venture view = aggregated from projects
✓ Project view = aggregated from milestones
✓ No data duplication — views are computed

The Core Principle: Each Level Is Identical in Shape

📁 Project

Has budget

🎯 Milestone

Days–weeks
Has owner
Has deliverables
